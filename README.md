# 🤖 Чат-бот школы «Удачный старт»

Чат-бот для автоматизации ответов на вопросы абитуриентов и записи на курсы подготовки к экзаменам.

## 📋 О проекте

Чат-бот решает проблему высокой нагрузки на сотрудников школы в период приёмной кампании (50–70 однотипных обращений в день). Бот автоматизирует ответы на частые вопросы и самостоятельную запись на курсы.

**Целевой показатель:** снижение нагрузки на приёмную комиссию на 40%.

---

## ✨ Возможности

- 📚 Рассказывает о курсах (история, математика, русский язык)
- 📅 Показывает актуальное расписание занятий
- ✍️ Записывает на курс с автоматическим сбором данных (имя, телефон)
- 🤝 Предлагает связаться с менеджером при сложных вопросах
- 📊 Ведёт JSON-логирование всех взаимодействий
- 📈 Рассчитывает метрику Accuracy (точность распознавания)
